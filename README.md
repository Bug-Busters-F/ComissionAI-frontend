# Gestão de Regras de Negócio - Front-end

Este é o repositório da aplicação front-end do sistema de **Gerenciamento de Regras de Negócio**, um projeto desenvolvido pela equipe Bug Busters para o **6º semestre de Análise e Desenvolvimento de Sistemas** da Fatec São José dos Campos, em parceria com a **Dom Rock**.

O front-end é responsável por disponibilizar a interface web do sistema, permitindo que gestores cadastrem regras de negócio, acompanhem simulações de comissionamento, analisem pendências e revisem os resultados antes da ativação das regras.

Acesse o repositório principal do projeto aqui ->  
<a href="https://github.com/Bug-Busters-F/API-6">Gestão de Regras de Negócio</a>

Instruções para rodar o projeto acesse  
<a href="./CONTRIBUTING.md">CONTRIBUTING.MD</a>

A aplicação front-end é responsável por:

- Permitir o cadastro, a edição e a consulta de regras de negócio.
- Apresentar o fluxo de criação, simulação, revisão e ativação de campanhas de comissionamento.
- Exibir resultados de simulações, custos projetados, pendências, anomalias e sugestões de ajuste.
- Permitir a confirmação humana antes da ativação de uma regra em produção.
- Consumir as APIs do back-end e do serviço de IA.

O objetivo é oferecer uma interface web simples e organizada para que gestores possam administrar regras de negócio, simular seus impactos financeiros e acompanhar os cálculos de comissionamento com rastreabilidade.
